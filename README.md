I analyzed a dataset containing 20,640 housing records with 9 features such as median income, average rooms, house age, population, and location.

I started with exploratory data analysis and found that median income is the most influential factor affecting house prices.

I built a Linear Regression model with an R² score of 0.59. Then I improved the model using Random Forest Regressor, which increased the performance to 0.79.

The results showed that house prices depend more on income level and location than on house size alone.
